1

Kane reads the page

For each place and time, tzproof starts Chrome in that time zone with its clock moved. Kane CLI uses your site like a person and stores the dates it sees.

2

Code judges the date

tzproof works out the right calendar day for that user. Kane checks too, but in our runs its own check passed a wrong date in 1 of 5 cells, so the code decides.

3

Claude fixes it

Red cells and Kane's evidence go to Claude Code. It edits only your app, and every clock runs again until all are green.
